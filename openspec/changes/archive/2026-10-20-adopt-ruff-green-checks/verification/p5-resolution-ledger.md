- `B023` is retained only for `docker/process.py:1023` (`returncode`, `stage_end`): the action runs inside the current loop iteration and the enforcement gate requires the exact `start_action` signature.
- `B010` is retained only for the two dynamic `setattr(error, "cleanup", self)` sites; direct attribute assignment on `BaseException` is rejected by ty.
